Requirements:
* Draw each day's CGM measurement values in a line chart
* Each day's line chart would have a different color for clear distinction
* Line charts can be overlayed
* Above the line chart, the user is able to select which days' lines to be displayed
* When the mouse hovers over a particular line, that line gets wider, and the other lines are greyed out. The date is also highlighted in the date selector area
* When the mouse hovers over a particular date in the date selector, that day's line gets wider, and the other lines are greyed out. The date is also highlighted in the date selector area
